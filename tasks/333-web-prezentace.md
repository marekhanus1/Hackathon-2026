# 333 – Moderní HTML webová prezentace projektu Narsil

## Cíl
Vytvořit samostatnou moderní HTML webovou prezentaci ze všech aktuálních podkladů na GitHubu s důrazem na minimalistickou moderní grafiku (zaoblené obdélníky, Bento Grid, čisté vektorové ilustrace) v meruňkové a lososové barevné paletě a se zachováním prezentačního režimu.

## Soubory
- `pitch/slidy/` (`index.html`, záloha `klasicke-slidy-tmave.html`)
- `pitch/snimky/README.md`
- `tasks/333-web-prezentace.md`

## Hotovo když
- `pitch/slidy/index.html` obsahuje všech 9 sekcí (koncept, problém, kontext, 4 pilíře + interaktivní telefon, ekonomika času, gamifikace, 21denní data ze Zrcadla a Mapy hodnoty, demo scénář, soukromí/architektura/FAQ) s moderní minimalistickou vektorovou grafikou.
- Funguje přepínač 3 palet (*Meruňkový úsvit*, *Lososový korál*, *Večerní meruňka*) i *Režim prezentace* (`P`/`F`, šipky `←`/`→`, poznámky `N`).
- Původní tmavé slidy jsou zachovány v `pitch/slidy/klasicke-slidy-tmave.html`.
- HTML a JS projdou validací bez chyb.
