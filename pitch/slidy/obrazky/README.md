# Obrázky do prezentace (`pitch/slidy/obrazky/`)

Do této složky můžete volitelně nahrát reálné screenshoty z telefonu. Prezentace `../index.html` je automaticky načte do 5. slidu (**Klíčové obrazovky aplikace**):

- `screen-1.png` → levý telefon (**Večerní smlouva**)
- `screen-2.png` → prostřední telefon (**Ozvěna**)
- `screen-3.png` → pravý telefon (**Pohyb / Přehled**)

**Ještě jednodušší varianta:** Screenshoty můžete nahrát i přímo v prohlížeči přes tlačítko **`✎ Upravit`** kliknutím na rámeček telefonu a pak prezentaci uložit tlačítkem **`⬇ Uložit HTML`**.
